# Guias

Esta seção reúne os **guias de desenvolvimento** do projeto.

Aqui serão descritos os passos práticos para configurar o ambiente, executar o projeto localmente, contribuir com código e seguir as convenções adotadas pela equipe.

Novos guias serão adicionados conforme forem necessários durante o desenvolvimento do projeto.
